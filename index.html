Guide Pratique

Architecture du Projet DevOps sur Azure

Voici la structure complète pour héberger ce portfolio sur Azure en utilisant Docker, Terraform et GitHub Actions.

1. Dockerfile (Nginx) Docker 
FROM nginx:alpine
COPY index.html /usr/share/nginx/html/index.html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
2. main.tf (Azure) Terraform 
provider "azurerm" {
  features {}
}

resource "azurerm_resource_group" "rg" {
  name     = "rg-portfolio-ali"
  location = "France Central"
}

resource "azurerm_service_plan" "appserviceplan" {
  name                = "asp-portfolio"
  resource_group_name = azurerm_resource_group.rg.name
  location            = azurerm_resource_group.rg.location
  os_type             = "Linux"
  sku_name            = "F1" # Free tier
}
3. deploy.yml GitHub Actions 
name: Build and Deploy to Azure
on:
  push:
    branches: [ "main" ]

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v3
    - name: Set up Docker Buildx
      uses: docker/setup-buildx-action@v2
    - name: Deploy to Azure App Service
      run: echo "Deployed portfolio to Azure!"
